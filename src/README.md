### Описание папочной структуры проекта:

| Путь                                               | Назначение папки                                        | Дополнение                                                                                                                                                                                                                                                                                                                                                                                                                               |
|----------------------------------------------------|---------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `./config`                                         | Конфигурации системы.                                   | `bundles.php`<br/> Добавление новых пакетов в Symfony.<br/> `parameters.yaml`<br/> Значения параметров окружения системы.<br/> `services.yaml`<br/> Конфигурация всех сервисов системы.                                                                                                                                                                                                                                                  |
| `./config/packages`                                | Конфигурации пакетов системы.                           | Названия файлов конфигурации соответствуют внедренным в систему пакетам.<br/> `cache.yml` <br/> Представлена своя конфигурация  сервиса кеширования.                                                                                                                                                                                                                                                                                     |
| `./config/routes`                                  | Конфигурации роутинга системы.                          | По умолчанию стоит конфигурация роутинга через PHP аннотации.                                                                                                                                                                                                                                                                                                                                                                            |
| `./src/Controller`                                 | Контроллеры системы.                                    | Шаблон глобальной 404 ошибки **всего** приложения `./src/Controller/ErrorController.php` задается в конфигурации тут `config/packages/framework.yaml`.                                                                                                                                                                                                                                                                                   |
| `./src/Controller/AssistantControllers/ActiveCRUD` | Активные CRUD контроллеры.                              | `ActiveDoctrineCRUDController` <br/> Для MySQL сущностей.<br/>`ActiveDoctrineMongoCRUDController` <br/> Для Mongo сущностей.                                                                                                                                                                                                                                                                                                             |
| `./src/Controller/Api`                             | Реализации API ендпоинтов.                              | Конфигурация роутинга методов описывается через аннотации `FOS\RestBundle\Controller\Annotations\Route`.                                                                                                                                                                                                                                                                                                                                 |
| `./src/Doctrine`                                   | Хранилище классов для пакета ORM Doctrine.              | Конфигурируемого по пути `config/packages/doctrine.yaml` и `config/packages/doctrine_mongodb.yaml`.                                                                                                                                                                                                                                                                                                                                      |
| `./src/Document`                                   | Хранилище DataMapper объектов сущностей MongoDB.        | -                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `./src/Entity`                                     | Хранилище DataMapper объектов сущностей реляционных БД. | -                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `./src/Event`                                      | События системы и пользовательские.                     | `Subscribers`<br/> Подписчики на события системы. <br/> `CustomEvents` Кастомные пользовательские события.<br/> `Listeners` Слушатели пользовательских события, конфигурация задаться в `config/services.yaml`.<br/> `Handlers` Классы помощники сущностей для встраивания логики в события (конфигурируются в `config/parameters.yaml` значениями в массиве сопоставления сущности и класса помощника `rest_listener_comparison_List`). |
| `./src/Form`                                       | Формы для валидации данных сущностей.                   | `Type`<br/> Классы валидаторы сущностей.<br/> `Validator`<br/> Кастомные, встраиваемые в конструктор валидаторы разделенные по типу применения к сущности `Document/Entities`.                                                                                                                                                                                                                                                           |
| `./src/Repository`                                 | Репозитории взаимодействия с сущностями.                | Взаимодействие с сущностями из хранилища БД описывается непосредственно в репозиториях, разделенных по типам сущностей `Documents/Entities`.                                                                                                                                                                                                                                                                                             |
| `./src/Security`                                   | Хранилище классов для пакета Security.                  | `Authenticators`<br/> Классы аутентификаторы для сервисного пакета `security` конфигурируемого по пути `config/packages/security.yaml`.<br/> `Badges` дополнительные, встраиваемые проверки после аутентификации пользователя.                                                                                                                                                                                                           |
| `./src/Services`                                   | Хранилище реализаций сервисов.                          | `src/Services/Helpers/Response/ResponseData` класс обертка над API ответом                                                                                                                                                                                                                                                                                                                                                               |
| `./src/Traits`                                     | Хранилище трейтов встраивания общего функционала.       | -                                                                                                                                                                                                                                                                                                                                                                                                                                        |

### По этапная реализация нового API CRUD контроллера:

1) Создать и заполнить объект DataMapper по пути `./src/Entity` для реляционных сущностей Doctrine или `./src/Document` для документа MongoDB.<br> Важно описать все поля сущности, реализовать сеттеры и геттеры, а так же добавить к геттерам массив групп для их отображения при серилизации (см.п.5).
2) Создать репозиторий взаимодействия с сущностью по пути `./src/Repository` в соответсвующую сущности папку.<br> * Класс должен реализовывать интерфейс `Core\Repository\Interfaces\RestRepositoryInterface`.
3) Создать и описать  валидатор для сущности по пути `./src/Form/Type` унаследованный от `Symfony\Component\Form\AbstractType`.<br> Важно реализовать как минимум 2а метода `buildForm` и `configureOptions`.
4) Создать контроллер по пути `./src/Controller/Api/{VERSION_API}/...` <br> Наследуемый от одного из родительского контроллера `src/Controller/AssistantControllers/ActiveCRUD/ActiveDoctrineCRUDController` для реляционной сущности или `src/Controller/AssistantControllers/ActiveCRUD/ActiveDoctrineMongoCRUDController` для документа из MongoDB.
5) В контроллере задать переопределением конфигурацию: <br> - `$serializeGroups` Группы геттеров сущности DataMapper которые будут отображаться после серилизации объектов ответа,<br> - `$entityClass` Неймспейс класса сущности, <br> - `$typeClass` Неймспейс класса валидатора сущности.
6) Добавить необходимые методы для работы CRUD (реализовать можно лишь некоторые).<br> Вот перечисление родительских методов CRUD: <br> - `restListAction` Метод для вывода списка с пагинацией,<br> - `restShowAction` Получение сущности по значению ID, <br> - `restCreateAction` Создание новой сущности, <br> - `restUpdateAction` Обновление сущности (коллбек функция `$getEntityOrException` ожидает изменяемую сущность, либо ошибку.),<br> - `restDeleteAction` Удаление по ID сущности.
7) При необходимости добавить класс помощник для встраивания логики в событиях (`{After/Before}{Create/Update/Delete}`) взаимодействия с сущностью.<br> Реализовать его важно по пути `./src/Event/Handlers/Rest` наследуемый от абстрактного класса `Core\Event\Handlers\Rest\AbstractRestHandler` и реализующий интерфейс `Core\Event\Listeners\Rest\RestHandlerInterface` в методах которого и встраиваем логику.<br> Также важно добавить сущность и класс помощник в массив соответствий `rest_listener_comparison_List` находящийся в конфигурации по пути `./config/parameters.yaml`.
